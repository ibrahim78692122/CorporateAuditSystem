Financial Overview

This dashboard provides a quick overview of accounting transactions recorded in the Corporate Audit System.

Total Transactions shows the number of accounting entries stored in the system.

Total Transaction Amount represents the combined value of all accounting transactions.

Highest Transaction shows the largest individual transaction amount.

Average Transaction represents the average value of all recorded transactions.
